# Concrete Building Design and Structural Analysis Project

## Project Overview
This project involved the structural analysis and design of a reinforced concrete building, covering structural modelling, design checks, and detailing of its main structural components.

## Project Execution
The project was carried out collaboratively by a two-member student team. Structural modelling, analysis, and design were performed using engineering software, supported by relevant calculations and technical documentation.

## Design Scope
- Structural modelling, analysis, and design of the reinforced concrete building
- Structural verification and essential design checks
- Classification and grouping of beams and columns into design types
- Design of waffle slab systems
- Design of reinforced concrete staircases
- Foundation design, including determination of foundation dimensions, thickness, and reinforcement detailing
- Review and evaluation of structural design outputs

## Software Used
- ETABS
- SAFE
- AutoCAD
- Microsoft Excel

## Project Documentation
All available project materials are organized and categorized in the relevant project folder, including:

- Structural models and software files
- Design calculations and supporting materials
- Software-generated drawings and outputs
- Original project report in Persian
- English-translated PDF version of the project report

The folder provides access to the project's design materials, analysis files, and supporting documentation for academic and technical review.
