# Steel Structure Design and Structural Analysis Project

## Project Overview
This project involved the structural analysis and design of a steel building, covering structural modelling, design verification, and evaluation of its main structural components.

## Project Execution
The project involved structural modelling, analysis, and design using engineering software, supported by design calculations and structural verification procedures.

## Design Scope
- Structural modelling, analysis, and design of the steel building
- Structural verification and essential design checks
- Design and evaluation of steel beams and columns
- Assessment of structural behaviour under applied loads
- Review of structural design results and software outputs

## Software Used
- ETABS
- SAFE
- AutoCAD
- Microsoft Excel

## Project Documentation
The available project materials are organized and categorized in the relevant project folder, including:

- ETABS structural model and analysis files
- SAFE files and foundation-related design materials
- Structural design calculations and verification files
- AutoCAD drawings and related design outputs
- Supporting engineering files and software-generated results

The folder provides access to the available structural models, design files, and technical outputs for academic and engineering review.
