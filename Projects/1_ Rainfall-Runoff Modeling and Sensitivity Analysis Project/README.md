# Rainfall-Runoff Modeling and Sensitivity Analysis Project

## Project Overview
This project involved rainfall-runoff modeling and sensitivity analysis for a catchment in Golestan Province, Iran, using the HEC-HMS hydrological modeling software. The study focused on simulating runoff hydrographs, evaluating the influence of key hydrological parameters, and improving model performance through manual calibration.

## Project Execution
The project was completed individually as part of the Advanced Engineering Hydrology course at Amirkabir University of Technology during the second semester of the 2023–2024 academic year.

The modeling process involved developing the catchment structure, defining subbasin characteristics and rainfall inputs, selecting appropriate hydrological methods, running simulations, and comparing computed discharge hydrographs with observed data.

## Modeling Scope and Analysis
- Development of the catchment model consisting of seven subbasins and three main river reaches
- Preparation and processing of rainfall hyetographs for individual subbasins
- Application of the SCS Curve Number (CN) method for rainfall loss estimation
- Definition and evaluation of key hydrological parameters, including Curve Number (CN), impervious area, and basin lag time
- Application of the Muskingum routing method and evaluation of its parameters (K and X) for river reaches
- Simulation of rainfall-runoff processes and generation of runoff hydrographs
- Sensitivity analysis to investigate the effects of parameter variations on peak discharge, flood volume, and the rising and falling limbs of hydrographs
- Manual model calibration through successive adjustments of hydrological parameters
- Comparison of simulated and observed discharge hydrographs at the catchment outlet
- Evaluation of model performance and the influence of parameter changes on runoff response
